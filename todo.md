## 3. Proposed npm Scripts

All implementable with Node built-ins. Proposed `package.json` `scripts` block:

```json
{
  "build": "node scripts/build.mjs",
  "check": "node scripts/build.mjs --check",
  "clean": "node -e \"import('node:fs').then((fs) => fs.rmSync('dist', { recursive: true, force: true }))\"",
  "create": "node scripts/create.mjs",
  "dev": "node scripts/dev.mjs",
  "firmware": "node scripts/firmware.mjs",
  "page": "node scripts/page.mjs",
  "report": "node scripts/report.mjs",
  "serve": "node scripts/serve.mjs",
  "start": "npm run build && npm run serve",
  "test": "node --test scripts/",
  "setup": "git config core.hooksPath .githooks"
}
```

| Command                                      | Purpose                                                                                                                                                                                                                                                                                                    | Prio |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| `npm run dev`                                | Build, serve and rebuild on changes in `wwwroot/` and `scripts/` (`fs.watch` with `recursive: true`; Linux needs Node ≥ 20). Optional live reload via Server-Sent Events: the dev server injects `<script src="/__reload.js">` **only in dev**, so the CSP (`'self'`) still holds and `dist/` stays clean. | P1   |
| `npm run check`                              | Validation only, no output written. Used by the git hook and CI.                                                                                                                                                                                                                                           | P1   |
| `npm test`                                   | `node --test` (built-in runner) for `esc`, `slugify`, `safeExternalUrl`, `renderNav`, `aria-current`, link checker, sitemap.                                                                                                                                                                               | P2   |
| `npm run create -- …`                        | Extend existing script: `--tags a,b`, `--featured`, `--status`, `--repo <url>`, `--dry-run`. Use the same `YYYY-MM` source as the build.                                                                                                                                                                   | P2   |
| `npm run page -- "Title" [--nav\|--footer]`  | Scaffold a secondary page in `html/` from a minimal template, optionally append to `nav.json` / `footer-nav.json`.                                                                                                                                                                                         | P2   |
| `npm run firmware -- <suite> [--chip ESP32]` | Create `assets/firmware/<suite>/manifest.json` with the documented offsets (`0x1000`, `0x8000`, `0x10000`) and print the button snippet for the project page.                                                                                                                                              | P2   |
| `npm run report`                             | List `dist/` size, largest files, pages per size, images without WebP, unused assets.                                                                                                                                                                                                                      | P3   |
| `npm run remove -- <id>`                     | Remove a project entry and its page (with confirmation / `--yes`).                                                                                                                                                                                                                                         | P3   |
| `npm run check:external`                     | Optional HEAD requests (Node `fetch`) against external links (`links.repo`, nav). Manual only, never part of `build`.                                                                                                                                                                                      | P3   |
| `npm run package`                            | Create a deploy archive of `dist/` (`tar -a -cf` exists on Windows 10+, macOS, Linux). Only if hosting is FTP/manual upload.                                                                                                                                                                               | P3   |
| `npm run setup`                              | Activate the versioned git hooks (see 5).                                                                                                                                                                                                                                                                  | P2   |
