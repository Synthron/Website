## 3. Proposed npm Scripts

All implementable with Node built-ins. Proposed `package.json` `scripts` block:

```json
{
  "build": "node scripts/build.mjs",
  "check": "node scripts/build.mjs --check",
  "clean": "node -e \"import('node:fs').then((fs) => fs.rmSync('dist', { recursive: true, force: true }))\"",
  "create": "node scripts/create.mjs",
  "dev": "node scripts/dev.mjs",
  "firmware": "node scripts/firmware.mjs",
  "page": "node scripts/page.mjs",
  "report": "node scripts/report.mjs",
  "serve": "node scripts/serve.mjs",
  "start": "npm run build && npm run serve",
  "test": "node --test scripts/",
  "setup": "git config core.hooksPath .githooks"
}
```

## 5. Security / Production Config (`.htaccess`)

Live response headers of `https://dm7wb.de/` (2026-10-23): `Server: Apache`, `Cache-Control: no-store, no-cache, must-revalidate, max-age=0` (also for CSS), `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, `Content-Type: text/html` **without charset**, no HSTS, no `cf-ray`. The HTTP → HTTPS redirect could not be checked (corporate proxy intercepts plain HTTP).

- [ ] **P1** Replace the dev "no-store" caching with production rules: revalidate `.html`, long cache for versioned CSS/JS/images (D19, cache busting via `?v=`), revalidate unversioned files (firmware manifests and `.bin`). Add `AddDefaultCharset UTF-8`.
- [ ] **P2** Send the CSP as an HTTP header (allows `frame-ancestors 'none'`, which `<meta>` CSP ignores) and add `Strict-Transport-Security`, `Permissions-Policy` (e.g. disable camera/mic/geolocation; keep `serial` for the flasher pages).
- [ ] **P3** Force HTTPS redirect in `.htaccess` (WebSerial needs a secure context anyway). Safe because Cloudflare is DNS only (D18); if the proxy is ever enabled with SSL mode "Flexible", this redirect would loop.
- [ ] **P3** `ErrorDocument 403` returns a bare German string; consider pointing it to `404.html` or a styled page.
