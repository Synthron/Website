# XT4 – 4-channel Triac Interface / Phase-Fired Control (V2) – sub-page source

**Module type bits:** 101 (`DEV_XT` 0xA0). **Address:** `0xA0 + DIP(0–31)`. PCB: `hardware/pcbs/XT_V1` (100 mm × 77 mm). The tech note calls the triac module "XP … in testing", but the repository's `XP_V1` schematic is a PWM/MOSFET prototype (PCA9635 + BUK98150 MOSFETs, **no triacs**) – see [07_XP1.md](07_XP1.md). The triac board is `XT_V1`.

## Hardware
- **4 triacs** on **two separate mains voltage domains** (2 triacs each). Domains are isolated from each other and from the system.
- Each channel rated **up to 230 V AC / 1 A**. Triacs can get hot – note cooling/derating on the page.
- Two operating modes:
  1. **Switching** AC to a load (on/off).
  2. **PFC mode (phase-fired control):** triac fired with PWM-style phase angle for dimming/heating power control.
- Each domain has **zero-crossing detection (ZCD)** (TLP291 optocoupler). The module **measures mains frequency automatically** and compensates for frequency drift.
- Parts on XT_V1 (verified in schematic): **BT136-500** triacs (TO-220; the device itself is a 500 V / 4 A part, the module is specified for 230 V / 1 A), **MOC3043M** zero-crossing optotriac drivers (4×), 360 Ω / 330 Ω gate networks, **68 Ω + 10 nF RC snubber** across each triac, BC846 drive transistors, **TLP291** optocouplers for the zero-cross detection per domain (56 kΩ / 1 MΩ resistor networks, SM4007 rectifier diodes), standard slave hardware (STM32F103C8T6, MAX485E, SN65HVD232, AP1117-33, 5-bit DIP).
- Front panel: 4-LED style cover.
- All channels electrically isolated from the logic.

## Software
- Reserved registers: `REG_CH1…REG_CH4` (0x4–0x7), 16 bit (phase / power value per channel).
- **No firmware in repo yet** for XT (README: "Write Software for new PCBs – XT" open).

## Status
Hardware in testing; software pending. Safety note for the website: mains voltage – only for qualified persons.
