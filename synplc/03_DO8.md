# DO8 – 8-channel Digital Output (V2) – sub-page source

**Module type bits:** 001 (`DEV_DO` 0x20). **Address:** `0x20 + DIP(0–31)`.

## Hardware
- **8 outputs, 24 V compatible, 0.5 A each**.
- **Power stage: Infineon ITS4880R**, 8-channel high-side smart driver (PG-DSO-36) with per-channel status outputs.
- **Galvanically isolated** from the system voltage through **optocouplers**: 4 × TLP291-4 quad packages (U5–U8 in the schematic, 16 optocoupler channels) carry the control and status/feedback signals.
- **24 V rail switch:** FQP27P06 P-channel MOSFET (TO-220) switches the 24 V output supply; SM6T36A TVS on the 24 V rail.
- **24 V load supply must be provided on the module connector** (not from the bus).
- **Feedback / short-circuit supervision:** every output is measured back and compared to its set value; on a mismatch the module sets an error bit and (design intent) switches that channel off. Read-back exposed via register `REG_FB` (GPIOB 0–7).
- Front: 8 LEDs show the state of the outputs (case variant `front_led_8`).
- Standard slave hardware (STM32F103C8T6, MAX485E, SN65HVD232, jumper-selectable bus, 5-bit DIP, AP1117-33).
- PCB `hardware/pcbs/DO8_V1.2`, 100 mm × 77 mm. CubeMX: USART3 250 kBaud, TIM1 µs timer, CRC enabled. Noted in the tech note: DO8 was not improved much between V1 and V2 ("talking about you, DO8").

## Software
- Outputs on PA5–PA12 (`reg_out << 5`), feedback from PB0–PB7. Main loop refreshes outputs every ms and samples feedback.
- Commands: **Ping**, **Write 8-bit `REG_OUT` (0x1)** sets all 8 outputs (bit0 = channel 1), **Read 8-bit** `REG_FB (0x2)` and `REG_ERR (0xF)`.
- Automatic shutdown of faulty channels (`out_Poll`, `check_Output` comparison) is **prepared in code but currently commented out** – describe as "feedback available, automatic shutdown being finalised".

## Status
Hardware tested (dead alternative-switch channels were re-soldered). Firmware RS485 slave works.
