# DI8 – 8-channel Digital Input (V2) – sub-page source

**Module type bits:** 000 (`DEV_DI` 0x00). **Address:** `0x00 + DIP(0–31)`.

## Hardware
- **8 digital inputs, 24 V compatible**, in **two groups of 4**; the two groups are **galvanically isolated from each other** (separate grounds GND1 / GND2) and from the system via **TLP291-4 optocouplers** (2 × quad).
- Max input current limited to **2 mA** per channel (series resistor 2.2 kΩ + zener/transistor input stage: 5.6 V / 6.8 V zeners, BCX53 transistors, RC filter 470 nF/1 k).
- **Levels:** LOW = 0…5 V DC, HIGH = 10…33 V DC.
- **Protection:** ESD-safe, tolerates up to **33 V DC**, reverse-polarity protection, over-current limiting, SM6T36A TVS per channel, ferrite bead per channel.
- Connectors: 2-pole 5.0 mm screw terminals per channel (TBL009-500-02GY-2GY) – the reference ground of each input group must be connected for operation.
- Front: status LEDs (LED variants of the case: 4 or 8 LEDs; the board has 8 LED + 220 Ω).
- Bus: ribbon connectors, RS485 (MAX485E) / CAN (SN65HVD232), jumper-selectable; 5-bit DIP address; STM32F103C8T6; AP1117-33.
- PCB: `hardware/pcbs/DI8_V1.1`, 100 mm × 77 mm, 1.6 mm. Bus headers: 2 × (2×5) ribbon headers (IN/OUT), 2×3 SWD header, 1×4 header.
- Front panel: 8-LED cover (`Gehaeuse-front_led_8.stl`).

## Software
- Main loop reads `GPIOA->IDR` bits 5–12 into `reg_in` every ~100 µs.
- Address: `0x00 | (GPIOA & 0x1F)`.
- Supported RS485 commands: **Ping**, **Read 8-bit** register `0x0` (inputs) and `0xF` (error). Anything else → NACK (instruction/register error).
- Bit n of the input register = input n+1 (1 = HIGH).
- CubeMX: USART3 250 kBaud on PB10/PB11, TIM1 prescaler 72-1 (1 µs tick), CRC peripheral enabled.
- Register note: the tech note names the DI input register "0010", but the firmware uses `0x0` (see master page).

## Status
Hardware tested (dead channels from soldering were re-soldered/fixed). Firmware basic RS485 slave works.
